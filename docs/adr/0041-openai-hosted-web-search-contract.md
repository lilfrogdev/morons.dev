# ADR 0041: OpenAI-hosted web search contract

## Status and staging

Accepted before implementation, 2026-09-08, for a focused provider-contract increment. The owner requested OpenAI-hosted web access as the default, and authorized focused PRs and merges. This increment adds bounded request/result decoding only; it does not route a tool, acquire credentials, make HTTP requests or change the Brave default. Separate dispatch/ownership and application/default increments must qualify before admission. This narrowly supersedes ADR0019's exclusion of hosted search as future work, not its credential boundary.

## Reviewed provenance

Official Codex459a79eb85400af759e9220c7bafb4429ae07516 `codex-rs/tools/src/tool_spec.rs` defines hosted `web_search`, including live/cache controls. Its configuration distinguishes cached from live access. The public [OpenAI web-search guide](https://developers.openai.com/api/docs/guides/tools-web-search) documents completed `web_search_call` actions (`search`, `open_page`, `find_in_page`), `url_citation` annotations, complete sources and explicit live access. API-key examples are not proof of native-account availability or billing. Public native-adapter source corroborates ChatGPT OAuth requests but its retries, model fallbacks, raw errors, guessed citations and partial completions are not adopted. No other application's credentials or browser state are used. The public OpenAI Python SDK's `response_function_web_search.py` and `response_output_text_annotation_added_event.py` additionally document nullable optional action fields and streamed annotation additions; these are bounded progress until reconciled with complete output.

## Contract

- One dedicated, tools-only search request for exact native `gpt-5.5`, independent of the parent coding model. The subsequent transport can target only the already reviewed ChatGPT Codex Responses HTTPS route with Morons attribution and the server credential broker. No API-key, cookie, alternate origin, model or alias fallback.
- Public tool input remains one bounded query (512 UTF-8 bytes). Only that query and fixed search instructions enter this request: no parent transcript, attachments, project guidance, skills or local function tools. Explicit hosted web_search/live access/low search context, required web-search tool choice, stream:true/store:false. No remote memory or unsupported output-token cap. Search contract revision1 is separate from unchanged coding Responses5.
- Search inference is subject to current data-use restrictions using native GPT5.5's reviewed unknown policy; login/store:false do not establish favorable policy. Dedicated dispatch must later bind provider/model/generation/source/policy durably, including child search within task ownership. A validated request object alone is not dispatch authority.
- Decode at most256KiB of complete SSE source using existing strict JSON/SSE primitives. Require contiguous sequence numbers, valid matching response identity/model/lifecycle, complete output items, valid terminal usage and clean stream termination. Deltas/progress alone cannot return a result. Bound complete-item collection to128 indices, require contiguous zero-based indices, and reconcile populated item/terminal sources. Reject local function calls, unsupported actions, contradictory sources, malformed/unknown event envelopes and incomplete streams. No raw diagnostic channel.
- A successful search result requires a completed search action (not merely a completion from model knowledge), one final assistant answer and at least one typed URL citation. Permit bounded search/open/find actions but do not execute their URLs locally. Limit8 hosted actions,10 citations,16KiB answer,512-byte titles and4KiB URLs. Only HTTP(S) source locators without credentials/control characters are admitted. No citations guessed from prose or reasoning. Citation offsets are bounds-checked and discarded; return a source list rather than reinterpret them as Rust byte-slice authority or silently rewrite Unicode text. Reconcile streamed annotation values with the complete message; nullable progress alone supplies no citation. Optional null action query/source/open-page URL fields grant no source authority.
- Reasoning is bounded untrusted metadata and is discarded; it is never the answer, citations or durable memory. Preserve only normalized answer/citations, action counts and validated token usage. Local96k input/32k output acceptance and byte/action/time bounds are not remote spending caps or refund guarantees.

## Follow-up admission requirements

Before changing the default, add a one-shot supervised broker-backed transport, immutable root/task search identity bindings and current policy admission; represent search usage separately from parent usage; retain historical Brave result decoding. Provide explicit configuration/disclosure, visible usable citations and bounded owner-triggered source navigation, not automation of a personal browser. Missing login, denial or uncertain effects must fail without silent fallback or retry. Run synthetic hostile-stream/identity/source/Unicode/bounds/privacy tests, all locked gates, exact-head CI and bounded live search/citation checks. Default functionality is not claimed by this contract-only increment.
